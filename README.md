# Hotel Reservation System

A web-based hotel reservation system that allows users to browse available rooms, make hotel bookings, and manage their reservations through an interactive interface.

## Features

- User registration and login
- Browse available hotel rooms
- Room booking and reservation management
- View existing bookings
- Manage user reservations
- Responsive web interface
- Separate frontend components and application logic

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- JavaScript-based frontend
- Database integration

## Project Structure

- `src/` - Application source code
- `bolt/` - Project configuration/components
- `css/` - Styling files
- `js/` - JavaScript files
- `index.html` - Main page
- `login.html` - Login page
- `signup.html` - Registration page
- `rooms.html` - Room listing page
- `my-bookings.html` - User bookings page
- `server.js` - Server-side application
- `package.json` - Project dependencies and configuration
